# 🍔 Vingo - Food Delivery Web Application

A full-stack MERN food delivery application that enables users to browse restaurants, place orders, make secure online payments, and track deliveries in real time.

---

## 🚀 Features

- 📍 Real-time Order Tracking using **Google Maps** and **Socket.io**
- 🔐 Secure Authentication with **Google One Tap Login**
- 💳 Online Payments with **Razorpay Payment Gateway**
- 📧 Password Reset via **Email OTP**
- 🛒 Shopping Cart & Checkout
- 📦 Order History & Order Tracking
- 🏪 Restaurant Owner Dashboard
- 🛵 Delivery Partner Dashboard
- 📍 Live Location Updates
- 🔒 JWT-based Authentication & Protected Routes
- 📱 Fully Responsive User Interface

---
